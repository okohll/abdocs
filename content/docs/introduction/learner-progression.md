The Agile Academy learning pathway enables you to transform your career. You can go from  a citizen developer to a no-code software architect. 
 
Citizen developers can create their own applications using no code. Software architects can build complex applications, including powerful workflow features and integrations with other applications.
 
To go on this journey requires no technical knowledge. Beginners - "citizen developers" - come from a diverse range of non-IT backgrounds. The only skills you need are the ability to think, be willing to learn, and be able to plan.
 
Agilebase will help you every step of the way. And you can stop at the level that is useful to you.
 
Agilebase enables citizen developers to pass through five stages on their way to becoming software architects:

1. [Citizen Developer Level 1]({{<relref "/docs/introduction/Learner-progression-levels/citizen-developer-level-1">}}) - personalise your own views
2. [Citizen Developer Level 2]({{<relref "/docs/introduction/Learner-progression-levels/citizen-developer-level-2">}}) - add new tables and views
3. [Citizen Developer Level 3]({{<relref "/docs/introduction/Learner-progression-levels/citizen-developer-level-3">}}) - work on existing tables
4. [Junior Software Architect]({{<relref "/docs/introduction/Learner-progression-levels/junior-software-architect">}}) - use advanced functionality, such as workflows and APIs
5. [Software Architect]({{<relref "/docs/introduction/Learner-progression-levels/software-architect">}}) - complete system control

See the pages on each level to look at what it allows. For any development, you'll need a [passkey]({{<relref "/docs/security-and-compliance/security-features/users/passkeys">}}) set up.
